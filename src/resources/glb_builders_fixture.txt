# Reference-runtime differential for the model-export builders that are ported into
# src/resources/glb.rs: `GlbTerrainBuilder.Build` and `GlbNavMeshExporter.AddAssetToSceneBuilder`.
#
# Probe: tools/probes/res-glb (ResGlbProbe.csproj), .NET SDK 10.0.401, against the shipped
# AssetRipper assemblies in `%LOCALAPPDATA%\Temp\opencode\ar-ref\Source\0Bins\AssetRipper.GUI.Free\Release`.
# Every case creates real generated objects through the shipped
# `TerrainData.Create(AssetInfo, UnityVersion)` / `NavMeshData.Create(...)` factories, sets the
# serialized fields through the generated property surface, invokes the shipped builder, converts
# the returned SharpGLTF SceneBuilder with the shipped `ToGltf2()`, and decodes every accessor
# semantically (so the rows are independent of the SharpGLTF binary encoding).
#
# Row grammar:
#   GIN|<tag>|<version>|<w>|<h>|<resolution>|<sx>|<sy>|<sz>|<name>|<heightCount>
#     the values written into the generated Heightmap; `w`/`h`/`res` are the requested values.
#   GHTS|<tag>|<csv i16>            the serialized Heights list
#   GREAD|<tag>|<w>|<h>|<res>       the values the shipped Heightmap property surface reads back
#                                   (modern subclasses stub Width/Height to 0; 5.0 keeps them and
#                                   stubs Resolution to 0)
#   NIN|<tag>|<version>|<name>|<meshCount>
#   NVTS|<tag>|<meshIndex>|<x,y,z;...>   a HeightMeshData Vertices list
#   NIDX|<tag>|<meshIndex>|<csv>          a HeightMeshData Indices list
#   GMESH|<tag>|<meshIndex>|<meshName>|<primIndex>
#   GPOS|<tag>|<vertexIndex>|<x>|<y>|<z>  decoded POSITION (round-trip "R" formatting)
#   GUV|<tag>|<vertexIndex>|<u>|<v>       decoded TEXCOORD_0
#   GIDX|<tag>|<csv>                      decoded indices
#   GNODE|<tag>|<name>                    a scene node
#   GEMPTY|<tag>|no-meshes|nodes=<n>      the model carried no mesh
#   GERR|<tag>|<exception>|<message>      the shipped call threw; `inner|` rows carry the cause
#
# The Rust test `glb_builders_match_the_reference_runtime` replays every row through the
# production builders and fails on any difference, including sign-of-zero differences.
